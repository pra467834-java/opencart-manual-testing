# OpenCart Manual Testing Project

## Project Overview
This project focuses on manual testing of an e-commerce website to verify its functionality and identify defects.

## Scope of Testing
- Registration and Login
- Forgot Password and Logout
- Product Search
- Wishlist
- Add to Cart
- Product Comparison

## Testing Activities
- Test scenario and test case design
- Positive and negative testing
- Functional, UI, and validation testing
- Expected vs. actual result verification
- Defect documentation

## Project Files
- OpenCart Test Cases
- OpenCart Bug Reports

## Tools Used
- LibreOffice Calc
- Web Browser

## Note
This is a manual testing practice project. Test results represent the activities documented in the included files.
